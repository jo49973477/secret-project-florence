# Dataset utilities

- `download_droid_sample.py` and `download_simplerenv_sample.py` obtain small
  example datasets.
- `repair_lerobot_metadata.py` modifies metadata in a selected dataset.
- `validate_univtac_lerobot_conversion.py` checks converted UniVTAC data.

Run from the repository root, for example
`uv run python scripts/data/repair_lerobot_metadata.py --help`. Review the
target dataset and command options before running repair or conversion tools.
